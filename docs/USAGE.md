# 使用说明

面向使用者。按下面的顺序走一遍，就能完成「打开 → 剪辑 / 校准字幕 → 导出」。

## 界面概览

```
┌──────────────────────── 顶栏：打开媒体 / 导出方式 / 保存工程 / 导出 ────────────────────────┐
│                                                                                            │
│   ┌──────────────────── 播放器 ────────────────────┐   ┌── 侧栏：片段 / 字幕 / 设置 ──┐   │
│   │  视频预览 + 字幕叠加                             │   │  工具区（固定）              │   │
│   │  播放 / −5s / +5s / ▶ 预览成片                   │   │  列表（可滚动）              │   │
│   └─────────────────────────────────────────────────┘   └──────────────────────────────┘   │
│                                                                                            │
│  时间轴：缩略图 + 波形 + 字幕块 + 片段标记 + 成片时间轴          − 适应 +  缩放 / 平移       │
│  状态栏                                                                                     │
└────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 1. 打开媒体（分两步）

点左上角 **打开媒体**，会进入两步向导：

1. **第 1 步：选择视频**
   在目录里单击视频文件加入「已选视频」（可多选，按加入顺序拼接）。选好后点 **下一步：选择字幕 →**。
2. **第 2 步：选择字幕（可跳过）**
   - 需要字幕：在字幕目录里单击 `.srt` / `.vtt` 加入；有多个视频时可用下拉指定这条字幕归属谁。
   - 不需要字幕：直接点 **只载入视频**，或保持空着点 **载入**（会按 `自动匹配` 勾选决定是否找同名文件）。
   - **自动匹配**默认勾选：会在视频同目录找 `片名.srt` / `片名.vtt`，以及 `片名.zh.srt`、`片名.en.vtt` 这类多语言文件，每条各自成为一条字幕轨。
   - **视频自带的字幕**：打开后字幕页会列出视频里的内嵌字幕流（`内嵌字幕（视频自带）`，默认收起，点标题展开）。每条可点 **提取并使用**，把它分离成一条 `.srt` 字幕轨（存在自动保存目录的 `extracted/` 下，源视频不动），图片字幕（DVD/PGS 等）无法提取，只能用外挂 `.srt`。

> 只做「整片压缩、不剪辑」时可以不载入字幕：时间轴没变，原来的 `.srt` 改名成输出视频同名即可继续用。

打开后，顶栏会显示工程名，状态栏显示「已载入 N 个视频、M 条字幕轨」。

## 2. 浏览与预览

- **播放 / 暂停**：空格，或点「播放」。
- **−5s / +5s**：前进后退 5 秒。
- **单击时间轴 / 刻度 / 波形**：把播放头定位到该处。
- **滚轮**：平移时间轴；**Ctrl + 滚轮**：以光标为中心缩放；`− / 适应 / +` 按钮也能缩放。
- **跟随输出时间轴**（默认开）：勾选后播放会按片段顺序播放，自动跳过没保留的部分；取消则自由浏览原片。
- **▶ 预览成片**：从第一段开始按输出顺序播放。

## 3. 编辑片段

### 在时间轴上

- **空白处拖拽**：新建一个片段（拖出起点和终点）。
- **拖片段两端的手柄**：只改起点或终点，另一端不动。
- **拖片段中间**：整体平移，时长不变。
- **Alt + 拖片段**：把它拖到另一个片段上，改变合并顺序。
- **Esc**：取消正在进行的拖动。

### 在「片段」页卡片里

- 卡片显示每段的 `起 → 止` 和时长；**左右两个时间输入框可精确改起/终点**。
- 卡片右上角：`⧉` 复制、`✂` 在播放头处拆分、`✎` 重命名。
- **直接拖动卡片**：上下拖动改合并顺序。
- 顶部工具：`撤销 / 重做 / 整片（不剪辑）/ 清空`。
  - **整片（不剪辑）**：每个源片自动铺满 `0 → 全长`，适合只压缩不剪辑。

> 所有片段变更都进入同一个撤销栈，`Ctrl+Z` 可撤销。

## 4. 按字幕选点剪辑（「字幕 → 选点剪辑」）

- **剪辑用字幕轨**：字幕页顶部的下拉决定「由勾选行生成片段」等操作用哪条字幕轨；换轨后生成片段、预览、导出都跟新轨走。内嵌字幕那一行默认收起，标题上会显示有几条、当前在用哪条。
- 上方可 **搜索字幕文本**、切换 **字幕轨**。
- 每行左侧有复选框；行尾 `起 / 终` 可把该行设为片段起点 / 终点。
- `由勾选行生成片段`：把勾选的行生成片段（相邻行会合并），可设置 **前留白 / 后留白** 毫秒。
- `用起止行生成`：按你设置的起点行、终点行生成一个片段。
- `全选可见` 只作用于当前搜索结果。

## 5. 字幕时间校准（「字幕 → 时间校准」）

进入这个子页会自动选中播放头所在的那一句（没有就选第一句），随后：

- **迷你时间条**：拖左/右手柄改起点/终点，拖中间整句平移。
- **上一句 / 下一句**：切换当前句（`↑` / `↓` 也可以），播放头会跟着跳。
- **步长 + 按钮**：`起点−/＋`、`终点−/＋` 只改一端；`整句前移/后移` 不改时长。按住 `Shift` = 步长 ×5。
- **单句循环**：开启后循环播放当前句，改完立即跳回新起点，适合边听边改。
- **精确时间**：直接输入 `00:00:01.200`，点「应用精确时间」。
- **整轨偏移**：填毫秒数，应用到本轨或所有轨（整条字幕一起平移）。
- **从源文件重载本轨**：放弃本轨所有矫正，回到源 `.srt`。

> 源 `.srt` 永远只读；矫正只改工程里的副本，立即对时间轴、预览、切点、导出生效，**不需要点"应用"**。状态行会显示「已校准 / 本轨已改 N 句 / 重叠 M 处」。

## 6. 导出设置（「设置」页）

- **三档方案**（顶部三个按钮）
  - ① **沿用原片**：所有参数锁定为原片值，体积约等于保留时长占比。
  - ② **720p 省体积**：分辨率高度压到 720、CRF 25、峰值码率上限 1000k，适合丢 1080p 进来压小。
  - ③ **自定义**：全部参数开放，可保存成自己的预设反复使用。
- **常用参数**默认展开，**高级参数**默认折叠；每项都有 ❓ 悬停说明和速查表。
- **导出位置**：默认在源视频旁新建 `片名_剪辑/`，可自定义文件夹与文件名。重名会整批编号 `_2` / `_3`，绝不覆盖。
- **允许覆盖同名文件**：即使勾选，也**永远不会覆盖源视频**。

## 7. 导出

点右上角 **导出**：

- 顶部「导出方式」选择 **精确模式** 或 **无损模式**。
- 若存在警告（放大转码、码率高于原片、无损多段漂移等），会先弹确认框，可返回改参数。
- **没选片段也能导出**：没有片段时点导出，会问「您目前没有选中片段，是否确认全量导出？」；确认后导出整片（适合只改画质/只压缩），取消则什么都不做。
- 导出完成后弹窗会显示 **输出文件夹** 路径，点 **打开所在文件夹** 会打开该文件夹并选中导出的视频文件。
- 产物：`片名_剪辑.mp4`（或 `.mkv`）+ 每条字幕一个 `片名_剪辑.<语言>.srt`。

也可以只导字幕：`时间校准` 页的 **只导出字幕**（或 `Ctrl+E`），不生成视频。

## 8. 工程保存与恢复

- **保存工程**：把当前工程（片段 + 字幕轨 + 参数）存成 JSON，随时用 **打开工程** 载入。
- **最近工程**：一键载入最近编辑过的工程。
- **自动保存**：每次改动都会写本机快照；关掉再开、甚至断电后重启，会提示自动恢复上次进度。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `← / →` | 后退 / 前进 5 秒 |
| `i / o` | 当前字幕行设为起点 / 终点 |
| `, / .` | 当前句整体前移 / 后移一个步长（`Shift` = ×5） |
| `↑ / ↓` | 上一句 / 下一句（播放头跟着跳） |
| `Ctrl+Z / Ctrl+Shift+Z` | 撤销 / 重做（片段与字幕通用） |
| `Ctrl+S` | 立即保存工程到磁盘 |
| `Ctrl+E` | 只导出矫正后的字幕 |
| 滚轮 | 平移时间轴 |
| `Ctrl + 滚轮` | 以光标为中心缩放 |
| `Esc` | 取消正在进行的片段拖动 |

## 常见问题

- **加载视频时一堆黑框闪？** 已修复（所有 ffmpeg/ffprobe 调用都带 `CREATE_NO_WINDOW`）。请用最新构建的 exe。
- **字幕没自动匹配上？** 确认字幕和视频在同一目录、且文件名为 `片名.srt` / `.vtt` 或 `片名.语言.srt`。也可以在第 2 步手动选。
- **无损模式起点会和选的差几秒？** 流拷贝只能从关键帧起刀，起点会提前到最近关键帧（状态/警告会提示）。要精确到帧请用精确模式。
- **无损模式多段合并字幕有点偏？** 流拷贝每段尾部约多 0.2s，逐段累积。多段合并请用精确模式。
- **导出的文件在哪？** 默认 `<源片目录>/<片名>_剪辑/`；导出完成弹窗里可「打开所在文件夹」。
- **打开工程提示视频不存在？** 工程只记录视频路径，移动了源视频就会这样；字幕本身已内嵌在工程里，不受影响。
